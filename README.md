# 7 Palavras

Jogo de dicas em que duas equipes tentam acertar palavras e somar pontos.

## Arquivos

```text
7Palavras/
├── index.html
├── README.md
├── assets/
│   ├── favicon.ico
│   └── favicon.svg
├── css/
│   └── sete-palavras.css
└── js/
    ├── banco-palavras.js
    └── sete-palavras.js
```

## Abrir o jogo

Abra `index.html` no navegador. O projeto não precisa instalar dependências nem compilar.

## Publicar com GitHub Pages

1. Envie todos os arquivos e pastas deste projeto para um repositório no GitHub.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`, depois salve.

O GitHub Pages vai publicar o `index.html` e mostrar o endereço do jogo nessa mesma tela.
